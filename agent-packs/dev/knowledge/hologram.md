# Hologram Agent

The Hologram Agent is a Verifiable Service that holds conversations, keeps memory and performs
trust-bound actions for its operator. It talks to people through the Hologram App (DIDComm) and
through a Hologram UI in the browser (AG-UI), and to other agents through A2A.

Binding a web session: the page shows a QR code and a short code; the person scans the QR with the
Hologram App and confirms the code on the phone.
