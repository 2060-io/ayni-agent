# Ayni Agent

The Ayni Agent is a Verifiable Service that holds conversations, keeps memory and performs
trust-bound actions for its operator. It talks to people through the wallet app (DIDComm) and
through a Ayni UI in the browser (AG-UI), and to other agents through A2A.

Binding a web session: the page shows a QR code and a short code; the person scans the QR with the
wallet app and confirms the code on the phone.
